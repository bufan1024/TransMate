# Chrome 网上应用店介绍草稿

## 名称

TransMate · AI 翻译

## 简介

在网页阅读时划词翻译、查看整页双语和提炼网页重点。可连接自己的 AI 服务。

## 详细介绍

选中网页文字后，通过右键或快捷键查看原文和译文。翻译卡片贴近选区，支持复制、重试、原文展开，以及 Chrome 浅色和深色主题。也可以在侧边栏输入文字，或继续核对已经翻译的选文。

在长文章里启用整页翻译时，TransMate 先翻译阅读位置附近的内容，滚动后继续。可切换双语和仅译文模式，也可为常读的网站开启自动翻译。网页总结在侧边栏显示来源和进度。

侧边栏支持原译对照、长文本分段、本机 PDF 选文和可选的本机翻译历史。含标准字幕轨的视频也可开启字幕翻译。扩展提供简体中文和英文界面。

设置中可保存并切换多套 AI 服务配置，支持 OpenAI、DeepSeek、OpenRouter、Claude、Gemini、Azure OpenAI 和自定义兼容服务。凭据保存在本机扩展存储中。
