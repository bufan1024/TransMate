# Chrome 网上应用店介绍草稿

## 名称

TransMate · AI 翻译

## 简介

在网页阅读时划词翻译、查看整页双语和提炼网页重点。可连接自己的 AI 服务。

## 详细介绍

选中网页文字后，通过右键或快捷键查看原文和译文。翻译卡片贴近选区，支持复制、重试、原文展开，以及 Chrome 浅色和深色主题。也可以在侧边栏输入文字，或继续核对已经翻译的选文。

在长文章里启用整页双语时，TransMate 先翻译阅读位置附近的内容，滚动后继续。网页重点总结在侧边栏显示。

设置中可以选择 AI 服务预设或填写兼容接口，并测试自己的连接。TransMate 只把当前功能所需的文字发给你配置的服务，凭据保存在本机扩展存储中。本机翻译历史可在侧边栏主动开启和清空。
