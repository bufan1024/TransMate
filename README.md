# TransMate

一个自带 AI 服务配置的 Chrome 划词翻译扩展。当前版本使用 Manifest V3，面向 Chrome 116 及以上版本。

## 安装与使用

1. 打开 Chrome 的 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录 `TransMate`。
3. 打开扩展的「选项」，填写服务地址、API Key、模型与目标语言，然后保存并测试连接。
4. 在网页中选中文字，右键选择「用 TransMate 翻译」，或按 **Ctrl+Shift+Y**（Mac 为 **Option+1**）。选区附近会出现翻译浮层，可复制译文、重试或关闭。也可以点击扩展图标打开侧边栏，手动粘贴文字翻译。若默认快捷键未生效，可在 `chrome://extensions/shortcuts` 查看或改键。
5. 在普通网页的正文或空白处右键，选择「整页双语翻译」或「总结网页重点」。也可按 **Ctrl+Shift+2**（Mac 为 **Option+2**）启动双语翻译。先翻译当前屏幕和下方约半屏的正文，收到译文就逐段显示，滚动后继续翻译新看到的段落。右下角可以取消或移除译文。按 **Ctrl+Shift+3**（Mac 为 **Option+3**）启动网页重点总结，结果在侧边栏显示，可直接复制。

划词浮层和侧边栏都可通过「译为」临时切换目标语言。划词浮层会立即重译当前选文，新选文使用设置中的默认语言。侧边栏在当前打开期间保留临时选择，可随时选回「默认」。划词完成后可点「在侧栏打开」，直接查看卡片中的原文、译文及目标语言。选文超过 5,000 字符时，可在卡片中将原文交给侧栏，再查看分段和请求次数后开始翻译。

通过扩展图标打开侧栏后，也可以点击顶部的「翻译本页」或「总结本页」。如果切换标签页后侧栏提示无法访问网页，可在当前网页通过右键菜单发起操作。

设置页的「术语库」默认停用。可以按目标语言保存、编辑或删除固定译法，最多保存 120 条。启用后，每次划词、侧栏或整页翻译只发送当前文字命中的最多 24 条术语。导出的 JSON 仅包含固定译法，导入时可确认替换本机术语，启用状态由本机设置决定。

在网页视频上右键选择「翻译视频字幕」可翻译浏览器能读取的标准字幕轨。支持切换原字幕和目标语言，播放进度变化时只展示当前字幕的译文。打开期间会随字幕发送请求，可在工具栏关闭。

侧栏的「翻译本地 PDF」可读取用户选择的本机 PDF 文本层。选择页码和一段文字后，点「使用选中文本」，再点「开始翻译」。PDF 内容在本机提取，只有提交的选文会发给 AI 服务。当前支持 Chrome 125 或更高版本、20 MB 以内的文件，预览最多前 60 页，并限制页面和整份文件的预览字数。扫描页需要 OCR。

设置页的「测试连接」会使用当前填写的配置发送 `Hello, world.`，收到有效译文后显示耗时和示例结果。检测可取消，45 秒后超时；检测不会自动保存配置。

### 让 Codex 或 Claude Code 安装

在本目录启动新的 Codex 或 Claude Code 会话，直接说「使用 install-transmate Skill，把 TransMate 安装到我当前的 Chrome，并验证」。项目已提供两者各自可发现的 Skill 和 Chrome DevTools MCP 配置。Agent 会先检查扩展目录，再尝试安装并核对扩展是否启用。

使用项目提供的 MCP 连接现有 Chrome 前，须在 `chrome://inspect/#remote-debugging` 开启远程调试，并在连接弹窗中点击「允许」。Claude Code 还会询问是否批准项目 MCP 配置；Codex 须将 **TransMate 目录本身** 标记为受信任后才会加载 `.codex/config.toml`，仅信任其父目录不够。这些确认完成后，Agent 可以执行安装。若当前 Agent 没有可用的浏览器连接，它会尝试操作 Chrome 的扩展管理界面，或准确说明剩余步骤。若同时开了多个 Chrome 配置文件，请指定要安装的配置文件；Agent 应核对配置文件后再操作。Chrome 149 之前版本可走扩展管理界面安装。

## AI 服务配置

支持 OpenAI 兼容的 Chat Completions、Claude Messages 和 Gemini GenerateContent。Chat Completions 预设使用以 `/chat/completions` 结尾的地址和 Bearer API Key。自定义服务可使用其他请求路径，也可选择 `x-api-key` 或 `api-key` 请求头。只有 `localhost` 和 `127.0.0.1` 可使用 HTTP 或选择无需密钥模式。接口地址不能包含内嵌账号、查询参数或片段。

使用 Claude 时选择「Claude」，填写 Claude Console API Key 和所用模型的 ID。默认地址为 `https://api.anthropic.com/v1/messages`。组织范围的密钥需要填写工作区 ID，单工作区密钥可留空。浏览器直连受组织策略限制。 [Claude API 认证说明](https://platform.claude.com/docs/en/manage-claude/authentication)

使用 **Gemini** 时，选择 Gemini 预设，接口地址保留 `https://generativelanguage.googleapis.com/v1beta`，并在模型栏填写目标模型 ID。API Key 通过 `x-goog-api-key` 请求头发送。划词、侧栏和网页总结使用 Gemini 常规响应，整页翻译使用流式响应。详见 [Gemini GenerateContent 接口](https://aistudio.google.com/api-reference/generate-content)。

可在设置页保存多套带名称的 AI 服务配置，在设置页「设为当前」，或从侧边栏的「AI 配置」切换。每套配置保存各自的服务、模型、密钥和翻译偏好。旧版保存的单套配置会显示为「默认配置」。

保存、测试或切换配置时，Chrome 会就对应的服务域名申请网络访问权限。扩展只请求这套配置的具体域名。不同服务商若采用其他请求或响应协议，需要单独适配。

选择「Azure OpenAI」时，填写 Azure 门户里的 HTTPS 资源地址（`https://<资源名>.openai.azure.com` 或 `https://<资源名>.services.ai.azure.com`）、该资源的 API Key，以及支持 Chat Completions 的模型**部署名称**。资源根地址、`/openai/v1` 或完整的 `/openai/v1/chat/completions` 均可填写，保存时会统一为完整地址。此预设使用 Azure OpenAI v1 的 `api-key` 请求头。Azure 的日期版本接口和 Microsoft Entra ID 不在此预设的支持范围内。[Microsoft Azure OpenAI v1 API](https://learn.microsoft.com/en-us/azure/foundry/openai/latest)

设置页不会回填已保存的 API Key。编辑同一套配置时，若服务、完整接口地址和认证方式都未变，密钥栏留空即可沿用这套配置的密钥。切换为无需密钥并保存会清除这套配置的旧密钥。删除配置也会移除它的密钥，或可单独清除当前编辑的密钥。更新或删除配置后，扩展会尝试撤销其他有效配置均未使用的旧域名权限。手动撤销会影响使用该域名的所有配置，重置会清除所有配置并尝试撤销全部已授权域名。若授权撤销失败，设置页会提示部分完成，并保留手动撤销入口。取消连接检测时，Chrome 的授权弹窗仍可能留下新的域名授权，可在列表中撤销。

## 数据与权限

- 扩展在用户主动发起划词翻译、手动翻译、整页双语翻译、网页总结、标准字幕翻译或连接检测时，向配置的 AI 服务发送相应文字。双语翻译只发送阅读位置附近的正文。网页总结按批发送提取的正文。网页操作过滤表单、导航、隐藏区域和子框架。未选中文字时，划词快捷键只显示提示。
- API Key 保存在本机扩展存储中，不通过 Chrome 同步；扩展会限制网页内容脚本读取该存储。客户端保存密钥仍不能提供服务器级保密，请只在可信设备上使用。
- 划词原文临时保存在本次浏览器会话的扩展存储中，以便后台休眠后仍可重试；浮层关闭或页面离开时会清理记录，新的浮层会替换旧记录。点击「在侧栏打开」时，原文和译文通过同窗口的一次性会话记录交给侧栏，读取后清除。
- 扩展自身没有后端、账户系统或使用统计。本机翻译历史默认关闭，开启后保留最近 100 条。
- `contextMenus` 提供网页右键入口。`activeTab` 和 `scripting` 在用户触发后访问当前网页。`sidePanel` 提供重点总结、手动输入和受限页面的备用入口。`storage` 保存配置和临时操作状态。AI 服务域名访问权限在配置时单独申请。

## 当前范围

划词浮层直接翻译上限为 5,000 字符，侧栏可分段翻译最多 30,000 字符。开始前会显示请求次数，费用由 AI 服务决定。停止或失败后可继续未完成的分段。选文浮层等待上限为 25 秒，侧栏每段翻译和连接检测分别为 45 秒。整页双语和总结沿用已配置的 AI 服务与目标语言，最多读取 30,000 字符或 300 段，超出时会给出提示。整页双语优先使用流式响应，服务返回普通 JSON 时按批显示。较长的页面可能产生多次 AI 请求。

网页功能适用于普通 HTML 页面。受 Chrome 限制的页面（例如 `chrome://` 页面）可通过侧边栏手动输入。跨源 iframe 中的选文可能因 Chrome 临时访问权限限制而无法读取。

后续优化与功能清单见 [ROADMAP.md](./ROADMAP.md)。

## 开发验证

接手代码时可从 [Agent 指南](./AGENTS.md) 查找入口、相关测试和代码架构。

扩展无需构建。使用 Node.js 20 或以上版本安装开发依赖并运行测试：

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

如果已安装可加载扩展的 Chromium 或 Chrome for Testing，可用 `TRANSMATE_CHROMIUM_EXECUTABLE="/path/to/chromium" npm run test:browser` 指定浏览器，不必下载 Playwright 的 Chromium。

单元测试覆盖配置校验、AI 响应处理、右键与快捷键事件路由。浏览器测试会建立临时 Chrome 配置文件和仅监听 `127.0.0.1` 的模拟 AI 服务，验证连接检测不保存配置、申请的域名范围、授权允许与拒绝分支、保存配置、侧栏页面译文、请求期间取消与重试、两个浏览器窗口各自消费选文、普通网页浮层，以及快捷键读取段落、输入框和同源 iframe 选文。测试结束会清理临时配置文件；不会连接真实 AI 服务或发起付费请求。

浏览器测试会模拟 `chrome.permissions.request` 和 `contains` 的返回结果；它直接调用扩展后台注册的右键和快捷键处理器并在真实网页执行脚本注入，不操作 Chrome 原生授权弹窗、右键菜单、物理快捷键或侧栏容器。发布前请在目标 Chrome 版本中手动检查：

1. 加载未打包扩展，在设置页保存服务配置，并在 Chrome 的授权弹窗中确认当前域名；核对设置页的授权域名列表。
2. 在普通网页选中文字，使用原生右键菜单选择「用 TransMate 翻译」，确认选区附近出现浮层、原文正确且译文有效；点击扩展图标确认侧边栏仍可手动翻译。
3. 在 `chrome://extensions/shortcuts` 确认翻译快捷键已分配；回到普通网页选中文字，按划词快捷键确认浮层显示译文，空选文时确认不调用 AI 服务。Mac 上按 Option+2 确认当前页显示双语译文，按 Option+3 确认侧边栏显示网页重点总结。
4. 在较长的网页启动整页双语翻译，确认当前阅读位置先出现译文，滚动到下方时继续翻译，并可移除译文。在同一页启动重点总结，确认结果出现在当前窗口的侧边栏。
5. 使用自己的真实 AI 服务配置执行一次「测试连接」。此步骤由用户在本机操作，可能产生服务费用。
